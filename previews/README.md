# Review previews

This directory is generated from insights whose status is `review`.

Preview pages:

- are generated by `scripts/build_previews.py`;
- contain `noindex,nofollow`;
- have no canonical public article URL;
- have no article JSON-LD;
- are visibly marked as review previews;
- are removed by the builder after the insight leaves `review` state.

Do not edit preview HTML by hand. Change structured data and rebuild.
