The original Transformer: shorter dependency paths, more parallel sequence computation

The 2017 Transformer replaced recurrent/convolutional sequence layers with attention-based encoder-decoder blocks, trading O(n) recurrent dependencies for parallel self-attention and constant path length while paying O(n²) attention cost and making position explicit.

WHY THIS MATTERS

The durable idea is more precise than 'attention won.' Removing recurrence changes the computational graph: known sequence positions can be processed in parallel inside a layer, distant positions connect through a short attention path, and sequence order has to be injected explicitly. The same paper also exposes the trade-off—self-attention compares all positions—and its evidence belongs to 2017 sequence transduction, not to every later LLM design.

MENTAL MODEL

RECURRENT LAYER

Sequential dependency chain

Table 1: O(n·d²) complexity, O(n) sequential operations and O(n) maximum path length between sequence positions.

SELF-ATTENTION LAYER

All positions interact in one layer

Table 1: O(n²·d) complexity, O(1) sequential operations and O(1) maximum path length — more parallel, but quadratic in sequence length.

Source problem

Recurrent and convolutional sequence-transduction architectures impose sequential computation or longer network paths between distant sequence positions, limiting parallelism and making long-range dependencies harder to learn.

Source thesis

The Transformer removes recurrence and convolution and uses attention-based encoder-decoder layers so positions interact directly through self-attention, reducing sequential operations and dependency path length while adding explicit positional encoding to represent sequence order.

CONCEPTS TO KNOW

Learn only the prerequisites that preserve the model.

learn

Transformer sequence-transduction architecture

The original model is an encoder-decoder architecture for sequence transduction, not a synonym for every later decoder-only language model.

learn

Self-attention

Self-attention is the mechanism that lets each sequence position combine information from other positions without a recurrent state chain.

learn

Sequence-computation parallelism

Removing recurrent dependencies lets known positions within a layer be computed with a constant number of sequential operations in the paper's comparison.

learn

Attention dependency path

Direct all-position attention gives a constant maximum path between positions, one of the paper's arguments for learning long-range dependencies.

learn

Positional encoding

When recurrence/convolution no longer encode sequence order structurally, position must be injected into token representations explicitly.

EXAMPLES

machine translation

An encoder must represent a source sentence while allowing distant words to influence each other without traversing a long recurrent chain.

Can self-attention connect the relevant positions directly while the layer computes positions in parallel?

autoregressive decoding

A decoder generates the next target token but self-attention would otherwise expose future target positions during training.

Why does the decoder mask future positions even though the architecture has removed recurrence?

long sequence

Sequence length grows far beyond the sentence lengths common in the original translation experiments.

Does the O(1) dependency path still justify full all-pairs attention when O(n²) sequence cost becomes dominant?

WHERE THE MODEL BREAKS

Useful does not mean sufficient.

  1. Full self-attention has O(n²·d) per-layer complexity in sequence length, so the parallelism and constant path length are not free for long sequences.
  2. The original Transformer is an encoder-decoder sequence-transduction model; later decoder-only LLMs are descendants, not the exact architecture established by this source.
  3. Masked decoder self-attention preserves autoregressive output dependence, so O(1) sequential operations per layer should not be read as fully parallel autoregressive generation.
  4. The WMT 2014 BLEU/training results are historical evidence from the paper's tasks and hardware, not a universal statement that attention-only architectures dominate every current sequence problem.

PERSONAL ACTION MAP

Convert understanding into a decision.

Use now
  • When explaining why Transformers displaced recurrent sequence layers, use three separate dimensions—parallelizable layer computation, dependency path length and per-layer sequence complexity—instead of saying only 'attention is better'.
  • When reading modern LLM material, distinguish inheritance from the 2017 Transformer from claims actually demonstrated in the original encoder-decoder paper.
Try
  • For a sequence length n and representation dimension d, compare the Table 1 recurrent versus self-attention complexity/path terms and identify where n² attention cost becomes the limiting dimension.
Learn
  • scaled dot-product attention
  • multi-head attention
  • masked decoder self-attention
  • positional encoding
  • later decoder-only Transformer evolution
Build
  • A minimal visualization that lets sequence length change and shows recurrent sequential depth versus self-attention pair count/path length without claiming one is always cheaper.
Watch
  • Long-context attention mechanisms that change the original quadratic sequence-length cost while preserving useful dependency paths.
Ignore for now
  • Retrospective claims that the 2017 paper directly proved the architecture or scaling behavior of present-day decoder-only LLMs.
