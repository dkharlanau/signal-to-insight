# Signal to Insight v0.1.0

The first public source release freezes the validated source-to-review system, its generated public knowledge surfaces, and one intentionally reviewed proof path.

## Highlights

- Whole-source mapping, evidence-backed Knowledge Delta, Source Decision, prerequisites, and learning prompts.
- Cumulative concept graph with strict review/publication boundaries.
- Frozen 20-source structural cohort and retrieval regression benchmark.
- Public library, concept pages, discovery metadata, and golden walkthrough.
- Digest-protected external research-evidence packet with fail-closed privacy and authority limits.

## Verify

Run the [golden quickstart](../docs/GOLDEN_QUICKSTART_RELEASE.md). Release assets include a deterministic source archive and checksums from the tagged commit.

## Compatibility and non-goals

This release does not publish the nineteen review-only insights, claim human delayed-recall success, embed universal source extraction, or grant operational authority to downstream consumers.
