Why the edges exist

Relations are typed and evidence-linked. The validator rejects dangling concepts, dangling insights, duplicate semantic edges and relations without shared evidence.

FromRelationToRationale
Controlled execution depends on Execution history Consequential work cannot be reconstructed or evaluated later without a durable history of execution.
Controlled execution depends on Protected data separation Governed orchestration should not require broad access to protected data simply to observe or control work.
Controlled execution depends on Human-agent task equivalence Production work needs a stable task model when execution moves between an agent and a human reviewer.
Controlled execution depends on Policy as code Explicit policy decisions make authorization boundaries reviewable and testable instead of implicit in application code.
Controlled execution depends on Observability Operators need structured telemetry to inspect execution health even when business evidence lives in a separate durable record.
Execution history enables Replayable evaluation Historical execution state becomes reusable evaluation material only when enough context can be reconstructed reliably.
Durable execution related to Controlled execution Durability addresses continuity of work; controlled execution additionally requires authority, evidence, intervention and other governance controls.
